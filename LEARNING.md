# Learning

SARIF contains declarations about artifacts. URI text, base chains and indices
can agree without authenticating a file or linking diagnostics to one root cause.
Keeping input pointers and occurrence indices makes that distinction inspectable.

Default startColumn=1 and endLine=startLine are specified metadata defaults.
Missing endColumn depends on source length, which this tool deliberately cannot
know. The same numeric columns under UTF-16 code units and Unicode code points
are not interchangeable. An exclusive endpoint equal to start admits an insertion
point; a smaller same-line endpoint is invalid.

Validation order is observable behavior: an unused cycle or malformed late
declaration must prevent releasing earlier rows, even if an unsupported feature
was seen first. Frozen complete expected reports and deliberate mutations checked
that errors cannot be disguised by first-reference selection or invented bounds.

Injected write failures were insufficient on their own: the actual closed pipe
found Python's shutdown flush changing exit status. Test the process boundary
when promising delivery behavior. LF/CRLF differences belong to that boundary,
not a semantic oracle change.
